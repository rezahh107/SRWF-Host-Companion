# SRWF Host Companion v0.1.0

First personal/project-specific GitHub release of SRWF Host Companion.

## Highlights

- Adds the Owner-facing `Settings → SRWF Host` workflow for selecting the SRWF Registration page and explicitly applying the canonical Full Width host template.
- Adds read-only diagnostics and `Check Again` drift verification without hidden repair.
- Provides the native Full Width SRWF host canvas while preserving the Twenty Twenty-Five header, footer, navigation, and safe RTL gutters.
- Includes Persian/RTL admin qualification, authorization/nonce/target-edit boundaries, keyboard/focus checks, diagnostic privacy checks, and scoped machine-detectable accessibility checks.
- Includes the real-browser mechanical Owner E2E path from login through settings, apply, frontend verification, return, and read-only `Check Again`.

## Release requirements

- WordPress: `7.1+`
- PHP: `8.3+`
- Qualified target: WordPress `7.1.1` / PHP `8.3.33` / Twenty Twenty-Five `1.5`
- License: `GPL-2.0-or-later`
- Author: Reza Hashemi Hosseini

## Installation

Download `srwf-host-companion-0.1.0.zip`, then install it through WordPress under **Plugins → Add New → Upload Plugin**.
